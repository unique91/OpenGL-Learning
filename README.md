# OpenGL-Learning

A step-by-step journey into modern OpenGL using GLFW, GLEW, and GLSL.

The goal of this repository is to understand the fundamentals of modern OpenGL, from creating a simple application window to rendering complex 3D scenes.

## Technologies
- C++17
- OpenGL 3.3 Core Profile
- GLFW
- GLEW
- GLSL
- Visual Studio IDE 2022
